# 鱼三药寮屋 · 星座月刊（本地 Demo）

公众号 H5 内容平台：**内容分发（主干）+ 答疑（钩子）+ 活动位（占位）+ 付费内容墙（预留）**。
用户之间不互动（合规考量）。本版不接任何真实 API / 微信授权 / 支付，全部本地模拟。

## 快速开始

- **双击 `index.html`** 直接打开；或 `node serve.js` 后访问 http://localhost:8080 （手机/微信内预览用）。

## 栏目结构

1. **药寮方（内容）**：图文内容 + 视频占位卡（第三方嵌入），主干。
2. **来问（答疑）**：仅购买用户可提问 → 审核 → 老师回复，用户间不互动。
3. **活动**：占位，线下沙龙等宣发（敬请期待）。
4. **良方铺（付费）**：完整付费内容墙（价格 + 解锁状态），不接真实支付。

## 答疑钩子机制（兑换码）

```
运营后台批量生成兑换码 → 导出给合作方/购买用户
   ↓
购买用户在「来问」输入兑换码 → 获得 1 次提问机会（用完失效）
   ↓
提问（可选公开/私密）→ 审核 → 老师回复
   ↓
公开的进「精选问答」→ 非购买用户可看（引流引导购买）
```

- **提问门槛**：仅购买用户（有提问机会）能提问；被拒问题「修改重提」不消耗新机会。
- **精选问答**：非购买用户可浏览公开问答，作为内容引流。
- **预留**：`loginWithWechat()` / `openid` 已预留，未来同主体后用 `unionid` 自动串联，替换兑换码。

## 后续接真实接口

所有数据读写都经 `service.js`，页面不直接碰存储。接真实后端时把 service 层实现替换为 `fetch`，函数签名不变；`auth.js` 的 `loginWithWechat()` 接微信 OAuth；付费内容、视频通过第三方（视频号/千聊/小鹅通）嵌入。

## 资质要点（摘要）

- 域名 ICP 备案（底线）；视频不自建，走第三方嵌入（避免《信息网络传播视听节目许可证》）；直播因资质问题本期不做；知识付费早期挂靠第三方；用户间不互动规避 UGC 类资质；出生信息属敏感个人信息，需合规收集与脱敏；内容避开"算命/封建迷信"话术，不碰医疗/投资/法律建议。
